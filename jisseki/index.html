実際にお受けしている仕事の種類です。取引先名・数量・金額は書いていません。「こういうことを頼めるのか」の目安にしてください。

ステンレスフランジの旋盤加工（材料支給・繰り返し品）

品物ウェルドネックフランジ JIS 10K（SUS F304 型打ち鍛造）、DIN PN16 の図面品、SUS316L の板材・鍛造材からのフランジ
加工内容外径・座面・ハブの旋盤仕上げ。サイズにより内径仕上げ（下穴あり）を含む。ボルト穴は含まない
進め方取り代を決めて受入確認 → 初品の寸法測定記録 → 本数に入る → 完了検査（寸法・バリ・C面のかえり） → 1枚ずつ包んで納品
ロット数枚の単発から、繰り返しの量産まで

大径・厚物のフランジ（1枚から）

  • SUS316L の大径・厚物鍛造材の旋盤加工
  • 大径の外筒フランジ（鍛造材）の端面・内外径・厚さの一次加工
  • SUS316L 板材からの薄物大径フランジ

大径品は保持の仕方（内径をつかむか外径をつかむか）で端面のビビりや寸法のばらつきが出ます。当社では加工先と保持方法を先に決め、仕上げ前に一度測ってから仕上げる進め方にしています。

補修・再製作（1個もの）

  • 振動ふるい機の鋳物ケーシング：摩耗した軸受穴を、穴を広げて S45C のつば付きスリーブを入れる方法で補修。はめあいは中間ばめ、ベアリングは客先支給で現物合わせ。→ 補修方法の解説
  • 長年の加工先が廃業し、図面がない補修部品の再製作のご相談。→ 図面がない部品の製作

受けられる仕事の目安

  • 旋盤：丸物・軸物・フランジ。1個から繰り返しの量産まで
  • 材質：S45C・SS400・SUS303/304/316/316L・鋳物・アルミ・銅合金・チタン
  • 材料はお客様からの支給が基本です。材料不良時の扱いは注文時に取り決めます
  • 穴あけ・タップ・溝・キー溝は内容により対応します
